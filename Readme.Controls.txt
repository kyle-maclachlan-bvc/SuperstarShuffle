Thank you for opening this Readme. I have provided this for the purpose of giving you control context for playing the game when using the computer and NO additional controllers.

I would like it noted, if you pair 4 controllers to your computer, Unity will identify all 4 controllers and pair them to player 1, 2, 3, and 4 in the game. However, as I have been building this game to be controllable on a desktop to make things work, I have keyboard controls that will control all 4 players.

Keyboard Controls:
Enter: Confirm - this is how you will walk through dialogue boxes, such as during the game's Setup, minigame tutorial screen, and result screen. When you land on a space, this will be how you Buy the Space.
Backspace: Cancel - this is how you would cancel selections. When you land on a space, this will be how you decline buying the space.
Arrow Keys: At intersections on the board, you are able to choose a direction Left, Right, Up, or Down. At this stage there is no UI element to help identify which direction you are going in. First Intersection has Right and Down as options, Second Intersection has Up and Left. You cannot the incorrect directions. You would then hit the Confirm button to confirm your direction.

Q: player 1 - this will control the Red Character. 
W: Player 2 - this will control the Blue Character.
E: Player 3 - this will control the Yellow Character.
R: Player 4 - this will control the Green Character.

P: Pause - I do not have Pause set up yet. This would allow players to enter the pause menu which, depending on the state would change the effect of this function - Pausing to a Board Menu, Pausing to the minigame's controls, etc.


Okay, if you DO connect a controller, you can use it to play the game as well.

Controller Controls:
South Button: Confirm and Roll Dice. On the controller, the south button does EXACTLY what you would expect. It will roll your dice, and confirm your selections. Your Controller ID will exclusively control the correct character. Player 1 for the first controller, Player 2 for the second controller, etc.
East Button: Cancel Selection or Property Purchase.
Left Stick: You can choose your direction at intersections.
Start Button: Pause Game.

I hope, by the time you are doing a new check on the game, that I have a proper UI dialogue box for controls. Though as a heads up, since the controls are based on a controller, the UI controls will be based on those controls. Keyboard is SIMPLY FOR TESTING CONTROLS.
